# SynEye PWA

แอปนัดหมายและติดตามงานตรวจสอบสายไฟฟ้าภายใน (ต้นแบบ) — 2 แอปในไฟล์เดียว เปิดมาจะมีหน้าเลือก **แอปลูกค้า** / **แอปช่าง**
เต็มหน้าจอมือถือจริง (100dvh + safe-area) ไม่ใช่ภาพ mockup แล้ว กดปุ่ม/แท็บล่างเดินหน้าจอได้ 15 หน้า
แผนที่ใช้ OpenStreetMap ผ่าน Leaflet 1.9.4

## ไฟล์
- `index.html` — ตัวแอปทั้งหมด (self-contained ไม่ต้อง build)
- `manifest.webmanifest` — ตั้งค่า PWA (ติดตั้งบนหน้าจอหลักได้)
- `sw.js` — service worker: cache app shell + cache tile แผนที่ที่เคยเปิด
- `icon-192.png`, `icon-512.png` — ไอคอนแอป (placeholder รอไอคอนจริง)
- `.nojekyll` — ให้ GitHub Pages เสิร์ฟไฟล์ตามเดิม

## ขึ้น GitHub Pages
```bash
git add -A
git commit -m "SynEye PWA: full-screen mobile app"
git push
```
Settings → Pages → Branch: `main` / `root`
**สำคัญ:** ถ้าเคยเปิดเว็บนี้แล้ว service worker เดิมจะ cache ไว้ — เปิดใหม่หรือกด reload 2 ครั้งเพื่อโหลดเวอร์ชันใหม่ (CACHE เปลี่ยนเป็น syneye-v2 แล้ว)

## หน้าจอ
แอปลูกค้า: หน้าแรก · เลือกวัน-เวลา · ยืนยันนัดหมาย · ติดตามช่าง (LIVE) · แชท · ประวัติและผลตรวจ · แจ้งเตือน · โปรไฟล์
แอปช่าง: คิวงานวันนี้ · รายละเอียดงาน+นำทาง · สถานะเดินทาง · ฟอร์มผลตรวจ · ถ่ายรูป · ลูกค้าเซ็นรับงาน · สรุปงานประจำวัน

## หมายเหตุ
- ข้อมูลในหน้าจอเป็นตัวอย่าง ยังไม่ต่อ backend
- ตำแหน่งช่างเป็นการจำลองเดินตามเส้นถนนลาดกระบัง ของจริงให้แทนด้วยพิกัด GPS จากแอปช่าง
- tile ปัจจุบันใช้เซิร์ฟเวอร์ชุมชน (OSM-FR) เหมาะกับต้นแบบ ถ้าขึ้น production จริงควรใช้ tile ที่มี key ของตัวเอง (MapTiler / CARTO / self-host)
- ปุ่ม EN/ไทย อยู่มุมขวาบนของหน้าเลือกแอป
